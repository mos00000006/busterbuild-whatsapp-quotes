# Buster Build interactive flyer

The Netlify project serves the interactive Dezemba Build Blitz flyer at `/`. Its existing full quotation page is preserved at `/quote/`.

The flyer displays four PNG pages with tappable product markers. Customers choose quantities and open a prefilled WhatsApp request; WhatsApp asks them to choose a contact and press Send. No salesperson number is configured in the flyer.

The promotion is dated 25 November–15 December 2026. Prices, stock and variants require store confirmation.

This repository is connected to the existing Netlify site. The production branch is `main`; `netlify.toml` publishes the repository root.
